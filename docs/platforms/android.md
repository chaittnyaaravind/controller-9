# Android

## Permissions (complete list, as merged into the APK)
| Permission | Why | When |
|---|---|---|
| `INTERNET` | TCP/UDP to the host on the LAN | always (normal permission) |
| `ACCESS_NETWORK_STATE` | detect Wi-Fi loss/return for fast reconnect | always |
| `CHANGE_WIFI_MULTICAST_STATE` | receive DNS-SD replies (multicast lock) while the host list is open | only during discovery |
| `CAMERA` | scan the pairing QR code | runtime prompt, only when the scanner opens |
| `VIBRATE` | button clicks and game rumble | always |
| `dev.ninecontroller.android.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | generated by AndroidX Core to protect the app's internal broadcast receivers (signature-level, app-private) | automatic |

No location, contacts, storage, notification or background permissions. No analytics SDKs.

## Behaviour notes
- Motion: `TYPE_GAME_ROTATION_VECTOR` (fallback gravity → accelerometer) on a dedicated
  high-priority thread at 200 Hz (100 Hz option); registered only on the controller screen.
- Leaving the app (`onStop`) sends a paused frame → the host neutralizes everything.
- Identity: X25519 secret encrypted with a non-exportable AndroidKeyStore AES-GCM key; backups and
  device transfer excluded (`data_extraction_rules.xml`, `allowBackup=false`).
