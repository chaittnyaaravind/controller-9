# ADR 0006 — iOS: XcodeGen project + two Swift packages

**Status:** accepted (2026-10-17)

**Decision.** `protocol/swift` (NineKit: protocol + Network.framework client) and `apps/ios/Core`
(NineAppCore: stores, input engine, connection manager) are Swift packages that build and test on
macOS with `swift test`. The SwiftUI/UIKit app target (`apps/ios/App`) is generated by XcodeGen from
`apps/ios/project.yml`; the generated `.xcodeproj` is committed for convenience.

**Why.** Only the Command Line Tools are installed on the dev Mac, so iOS UI code cannot be
type-checked here; keeping logic in packages maximises what is verified before Xcode is available.
