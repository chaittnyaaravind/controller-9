# Controller-9 — guide for coding agents

- Android only. The phone is a Bluetooth LE Xbox Wireless Controller (HID over GATT); see
  `docs/DIRECT_BLUETOOTH.md` before touching `net/HidGamepad.kt`, `input/XboxHidReport.kt` or the GATT layout
  (macOS caches handles: never move them without a re-pair plan).
- The iPhone app, desktop companion and Rust protocol live on the `archive/multiplatform` branch.
- Run `tests/run_all.sh` before committing. Small, coherent commits. `tests/vectors` are generated by the
  app's tests — review changes, never hand-edit.
- Never claim something works without running it on a phone; record evidence in `tests/results/` and
  `docs/ACCEPTANCE_STATUS.md`.
- No telemetry, no cloud, no internet permission, no new permissions without documenting them in
  `docs/platforms/android.md`.
- The controller surface never animates input; a press shows and is sent on the next frame.
- Toolchain on the dev Mac: JDK `/opt/homebrew/opt/openjdk@21`, Android SDK `/opt/homebrew/share/android-commandlinetools`.
