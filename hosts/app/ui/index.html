    Rate
    Frames per second received, from the median gap between frames.
    Gap
    Time between consecutive input frames arriving at this computer.
    Jitter
    RFC 3550 interarrival jitter of input frames (variation in transit time).
    Lost
    Sequence gaps — frames sent by the phone that never arrived.
    Stale
    Late, duplicated or replayed frames that were discarded instead of applied.
    Invalid
    Datagrams that failed authentication or carried out-of-range values.
    Phone RTT
    Encrypted ping round trip measured by the phone. Half of it approximates network delay; it is not the full touch-to-game latency.
    Host proc
    Time from receiving a frame to handing it to the virtual controller.
    Neutral resets
    Times input stopped for longer than the timeout and the controller was released to neutral.

    Ports, slots and discovery apply after restarting the app. Nothing leaves your local network; there is no account and no analytics.

    First run
    1. 01Keep the phone and this computer on the same Wi-Fi network (5 GHz is best).
    2. 02Allow Controller-9 through the firewall when asked (TCP 47901 and 47902, UDP 47900). No Internet connection is needed.
    3. 03Pair, choose a layout on the phone, and press a button — the player bay lights up.

    Troubleshooting
    • No Wi-Fi at all? Turn Bluetooth on here; the phone falls back to Bluetooth LE automatically (slower — fine for most games, not ideal for fast racing). USB tethering is the lowest-latency option.
    • Phone can’t find this computer. Use the QR code or the manual address; some routers block discovery between devices (“client isolation”).
    • Input stutters. Check Lost and Jitter in Diagnostics. Move closer to the router or use 5 GHz.
    • Game ignores the controller. Confirm it appears in your OS game-controller panel. XInput-only games on Windows need Steam Input.
    • Buttons stuck? They can’t be: input older than the timeout is released automatically, and disconnects release everything.
